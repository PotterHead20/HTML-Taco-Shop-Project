# 🌮 HTML Taco Shop Project

A simple multi-page taco shop website built using pure HTML.

## Features

- Semantic HTML5 structure
- Responsive page layout
- Multi-page navigation
- About section
- Menu section
- Contact form
- Store hours page
- Custom CSS styling
- Images and tables

## Tech Stack

- HTML5
- CSS3

## Project Structure

```bash
HTML-Taco-Shop-Project/
│
├── index.html
├── hours.html
├── contact.html
├── style.css
├── img/
└── README.md
```

## Pages

- Home Page
- Store Hours
- Contact Us

## How to Run

1. Clone the repository

```bash
git clone https://github.com/PotterHead20/HTML-Taco-Shop-Project.git
```

2. Open the project folder

3. Run `index.html` in your browser
